An attacker used built-in Windows tools to gather system and hardware details. They do this to study a machine before the next stage of an attack. Water just wrote a rule to catch it.

What happened

A normal user account ran systeminfo chained with a registry query that lists the machine's disks. That combination reveals the storage layout and hints whether the machine is a virtual one, which attackers use to fingerprint a target.

What to do next

Keep an eye out for sandbox evasion. Attackers check disk and system info to spot virtual machines and avoid being analyzed, so that is the next gap worth closing.
