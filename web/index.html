🥄 What is Hunt?

A helper for security analysts. You give it something suspicious, it does the boring lookup work for you.

🔎 What does it do?

When a security analyst sees something suspicious — a website, a file, an IP address — they have to check if it's dangerous. Normally that means opening ten different websites by hand. Hunt does all of that in one step and gives you a single answer.

🧩 What can I paste in?

Any of these "clues" (analysts call them IOCs — indicators of compromise):

• An IP address — like a phone number for a computer (8.8.8.8)
• A domain — a website name (example.com)
• A file hash — a file's unique fingerprint (a long string of letters and numbers)

🚦 What do the answers mean?

MALICIOUS — it's dangerous. Block it.
SUSPICIOUS — looks risky. Investigate it.
UNKNOWN — not enough info. Keep an eye on it.
BENIGN — looks safe. Nothing to do.

🛡️ Does it make things up?

No. The answer is worked out with simple math from real threat databases — not by an AI that could guess wrong. The same clue always gives the same answer, and Hunt shows you exactly which sources it used.
